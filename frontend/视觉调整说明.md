# 田野档案 · 前端可读性调整 V1.1

本次在原 V1 前端基础上修改页面字体和部分显示文案，保留原有 Vue 2、Element UI、路由和接口逻辑。

## 调整内容

- 侧边栏导航文字由 13px 调整为 15px，导航分类由 11px 调整为 13px，并适当增加菜单高度。
- 工作台功能建设进度：标题调整为 15px，说明文字调整为 13px，状态标签调整为 13px。
- 工作台卡片、最近基地记录、表格、抽屉详情和其他待开发模块统一加大字号、提升辅助文字对比度。
- 移除页面装饰性的英文标签：RELEASE、DEVELOPMENT、OVERVIEW、ROADMAP、DATA COLLECTION、ORIGIN DATA、BASE DIRECTORY 等；保留技术名称 Spring Boot、MySQL 和版本 V1。
- 不修改后端请求路径、已有分页和系统状态功能。

## 在当前项目中更新（推荐）

如果已经在 `frontend` 中运行过 `npm install`，请使用“仅需替换的前端文件”补丁包：

1. 建议先在 IDEA 中提交或备份当前已修改的前端代码。
2. 将补丁 ZIP 解压到项目根目录 `agri-traceability-system`，使 ZIP 内的 `frontend/src/...` 对应现有项目的 `frontend/src/...`。
3. 覆盖提示时，确认只覆盖这 6 个文件：
   - `frontend/src/assets/styles/theme.css`
   - `frontend/src/components/AppShell.vue`
   - `frontend/src/views/Dashboard.vue`
   - `frontend/src/views/Bases.vue`
   - `frontend/src/views/ModulePending.vue`
   - `frontend/src/views/TracePreview.vue`
4. 不删除或覆盖 `frontend/node_modules` 和 `frontend/package-lock.json`。
5. 在 IDEA 终端中执行：

```powershell
cd .\frontend
npm run serve
```

若开发服务已经在运行，保存文件后 Vue CLI 通常会自动重新编译并刷新页面。可以按 Ctrl + F5 强制刷新浏览器。

## 验证项目

- 工作台的侧栏菜单和“功能建设进度”是否更易阅读。
- 是否不再出现 `RELEASE 01 — DEVELOPMENT` 等英文装饰文字。
- `/api/system/status` 和 `/api/bases/page` 是否仍正常返回数据。
- 种植基地分页列表、详情抽屉与移动端导航是否仍然正常。

本版本未加入新的业务接口，也未更改现有数据库和后端代码。
